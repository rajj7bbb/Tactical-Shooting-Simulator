# Tactical-Shooting-Simulator

A tactical first/third-person shooting simulator built in **C++** using **Unreal Engine**, developed as a 3rd semester academic project.

## 📌 About the Project

This project aims to build a small-scale tactical shooter that demonstrates core gameplay programming concepts — character movement, weapon mechanics, enemy AI, and basic UI — implemented using C++ within Unreal Engine.

> Status: 🚧 In Development

## 🎯 Features (Planned)

- [ ] Player controller with movement, crouching, and camera control
- [ ] Weapon system with shooting and reload mechanics
- [ ] Basic enemy AI (patrol → detect → engage)
- [ ] Hit detection and damage system
- [ ] Simple HUD (health, ammo counter)
- [ ] One playable test level/map
